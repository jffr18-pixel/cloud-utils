## Cómo crear cada página en Wix (5 pasos, se repiten para las 3)

1. **Crear la página:** Editor de Wix → **Menús y páginas** (icono de páginas a la izquierda) → **+ Añadir página** → ponle el nombre (p. ej. "Trámites de tráfico").
2. **Poner la dirección (slug):** en esa página → **⋯ → Configuración → SEO básico** → en "URL" escribe el slug del archivo (p. ej. `tramites-de-trafico`).
3. **Rellenar el SEO:** en esa misma pantalla, copia el **Título SEO** y la **Meta descripción** que vienen en la tabla del archivo.
4. **Montar el contenido:** ve sección por sección del archivo. Cada sección te dice qué añadir (🧱) y qué texto pegar (los bloques de texto). En Wix: **+ Agregar elementos → Texto** (título o párrafo), **Botón**, **Imagen**, o **Lista desplegable/Acordeón** para las preguntas frecuentes.
5. **Publicar** y pasar a la siguiente página.

### Detalles que importan
- **Un solo título grande (H1) por página** (el primero). Los demás títulos, como "Título pequeño" (H2).
- **Botones de WhatsApp:** al crear el botón → enlace → "Dirección web" → pega el enlace `https://wa.me/...` que viene en cada sección.
- **La calculadora** (solo en tráfico): se incrusta con **+ Agregar → Insertar código → Insertar HTML** pegando el archivo `landing-trafico/calculadora-embed.html`. Todo lo demás va nativo.
- **Cuando la página nativa esté terminada,** quita de esa página el recuadro grande con la landing antigua (si lo tenía): si no, el contenido saldría dos veces.
- **Enlaza las páginas desde el menú** de la web (Menús y páginas → arrastra las páginas al menú) y desde la portada.

---

## Después de publicar: avisar a Google (una vez, 10 minutos)

1. En Wix: **Panel de control → Marketing y SEO → Herramientas SEO → Google Search Console** (Wix lo conecta solo con tu cuenta de Google; sigue el asistente "SEO Setup Checklist").
2. Cuando esté conectado, Search Console recibirá el **sitemap** de Wix automáticamente.
3. En 1-2 semanas, busca en Google `site:burocraciazero.es` — deberían empezar a salir las páginas nuevas.
